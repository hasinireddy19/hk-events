# HK Events & Celebrations 🎉

A premium, mobile-responsive event management website for **HK Events & Celebrations** — India's culturally inclusive event planning service for weddings, baby events, birthdays, anniversaries, and corporate gatherings.

## ✨ Features

- **Interactive Wedding Roadmap** — A dynamic zig-zag graph timeline where users can select 3-day, 5-day, or 1-week wedding plans. Each day is represented by a clickable image node.
- **Glassmorphism Modal** — Clicking any image (roadmap nodes, service cards, or gallery items) opens a stunning dark glassmorphism popup with the image on the left and event details on the right.
- **Royal Cursor Effect** — A custom golden glowing cursor with a trailing ring, active in the hero section for a luxurious feel.
- **Glassmorphism Header** — A frosted glass navigation bar that stays fixed at the top.
- **Fully Mobile Responsive** — Every page is optimized for smartphones and tablets, including a slide-out mobile menu.
- **Smooth Animations** — Scroll-based fade-in effects, hover transitions, and micro-interactions throughout.

## 📄 Pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Hero section, services preview, wedding roadmap, testimonial, CTA |

## 🛠️ Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom properties, flexbox, grid, glassmorphism, media queries
- **Vanilla JavaScript** — Dynamic roadmap, modal system, cursor effects, mobile menu
- **Google Fonts** — Cinzel (royal headings), Poppins (body text)
- **Font Awesome 6** — Icons

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/hk-events-website.git
   ```
2. Open `index.html` in your browser — no build step needed!
